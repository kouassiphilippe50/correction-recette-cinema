# correction-recette-cinema
# La caisse de la cantine

Programme JavaScript qui calcule la recette sur les ventes de billets dans un cinema lorsque les billets sont vendus normalement et ceux qui sont vendus avec une reduction de 500 fcfa.

## Lancer le programme
node partie1.js
node partie2.js

## billets
1 - billet de moins de 16 ans  : 1 500 FCFA
2 - billet de plus de 16 ans  : 2 500 FCFA
3 - billet de plus de 18 ans avec reductions  500fcfa: 2 000 FCFA
